# Kaggle Pandas Micro-Course

## Overview
This repository contains my code, exercises, and datasets from completing the [Kaggle Pandas Micro-Course](https://www.kaggle.com/learn/pandas). It serves as a personal log of my progress and a reference guide for data manipulation techniques using Python's `pandas` library.

## Repository Structure
The repository is organized by course modules and includes the companion datasets used for the exercises:

*   **`Course1.py` - `Course6.py`**: Python scripts containing the code and solutions for various lessons in the micro-course.
*   **`C3-Apply&Map.py`**: Specific exercises focused on applying custom functions and mapping data.
*   **Datasets**: 
    *   `winemag-data-130k-v2.csv` (Wine reviews dataset)
    *   `Coffee_BobSue.csv`
    *   `data_kaggle.csv`
    *   `organizations-100.csv`

## Skills & Concepts Covered
Throughout these scripts, I practice core data analysis skills, including:
*   Creating, reading, and writing DataFrames.
*   Indexing, selecting, and assigning data.
*   Summary functions and maps (using `apply` and `map`).
*   Grouping and sorting data.
*   Handling missing data and standardizing data types (`dtype`).
*   Renaming columns/indices and combining datasets (`concat`, `join`).
